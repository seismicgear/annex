## Transparent application marks

Use `transparent/` for application headers, launchers, browser icons and native icon packaging. These owner-authorized derivatives change only the alpha channel; the original RGB pixels and square canvas remain unchanged. The manifest records both original and derivative hashes. Native icon generators preserve the alpha channel during resizing. Do not substitute the opaque original into a transparent mark placement.
